# 穩糖安心指南

給台灣一般成人與家屬的糖尿病衛教靜態網站。沿用此資料夾既有 HTML 草稿，完成樣式、互動與內容修訂；不改其他網站。

## 開啟成果

- 公開網站：https://jie-ling-2025.github.io/Diabetes-Health-Education/
- GitHub：https://github.com/jie-ling-2025/Diabetes-Health-Education
- 本機預覽：http://127.0.0.1:4175
- 可直接用瀏覽器開啟 `index.html`，同資料夾需保留 `styles.css`、`nojs.css`、`app.js`。
- 在網站資料夾開啟 PowerShell，重新啟動預覽（需電腦原有 Node.js，不需安裝套件）：

```powershell
node preview.cjs
```

服務只監聽 127.0.0.1；停止時按 Ctrl+C。預設連接埠 4175，若已被使用先確認是否為本網站預覽，不停止不明程序。

## 內容與資料

提供常見警訊、低血糖 15-15 原則、高血糖急症、疾病類型、監測／飲食／用藥分頁、日常照護、五項清單、三題知識測驗、大字切換與列印樣式。測驗僅檢查知識，不診斷、不判定安全。主要醫療內容為一般衛教，個人目標與處方須由醫療團隊決定。

無帳號、後端、API、外部字型、追蹤、Cookie 或瀏覽器持久儲存。清單與測驗只保留當次頁面狀態，重新整理重置。來源連結由使用者主動點擊後前往外站，適用該站政策。頁面使用 CSP 阻止程式對外連線。

查閱日期 2026-10-17；來源與對應主題列於頁尾。國健署頁面由搜尋服務取得官方頁內容，直接開啟多次逾時；另以可讀取的 NIDDK 原文交叉核對生活照護。未經醫護臨床審閱。
